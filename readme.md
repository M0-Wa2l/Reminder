# Reminder - Mohamed

A simple VS Code extension that displays positive and gentle reminder notifications while you code. It is designed to help you stay motivated, feel supported, and remember small self-care moments like drinking tea.

## What this extension does

- Shows uplifting reminders on a schedule when VS Code starts.
- Sends positive messages like "you are always good enough" and "you can do anything you want to do." 
- Helps you take small breaks and stay encouraged during work sessions.

## Features

- Simple reminder notifications.
- Start and stop commands for reminder control.
- Friendly messages to boost motivation.

## Commands

- `Reminder: Start Reminder 🔔` — begins the reminder notifications.
- `Reminder: Stop Reminder 🔕` — stops the reminder notifications.

## Installation

1. Install the extension from the VS Code Marketplace or run it locally from this repository.
2. Open the command palette with `Ctrl+Shift+P`.
3. Run `Reminder: Start Reminder 🔔` to begin receiving reminders.

## Usage

- After activation, reminders appear at regular intervals to keep your day positive.
- Use the stop command when you want to pause reminders.
